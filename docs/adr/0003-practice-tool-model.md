# Practice tool: section layout + flashcard drills, no input capture

The practice tool is a **visual reference + recall trainer**, deliberately NOT a key-input
trainer: it never captures keyboard/mouse input to validate combos — actual key practice happens
in-game. Layout per mode (PvE / AOS): three sections — Movement, Protected DPS, Unprotected DPS —
DPS-ordered, mirroring the in-game hotbar scheme. **Frontal Guard abilities group under Protected
with an FG badge** (rejected: FG as its own section — chosen for fewer sections to scan, despite
the BRIEF leaning toward a separate middle tier; the graded data model is untouched, so this is
presentational and revisitable). **CC is a badge (KD/Stun/Float/Stiff/Bound), not a section** —
Maegu's CC skills are almost all also top DPS skills, so a CC section would duplicate most of its
members. Drills: PvE = the Infinite Combo (with optional skills marked); AOS = one combo per
family (Flower Shroud #1 is the single ideal); priority-order drills are a later addition.
Decided 2026-06-11 in the Phase 1 grill.

**Amended 2026-06-11 (Phase 2 iteration):** after using the v1 flashcard quiz, the user replaced
recall quizzing with **combo strips** — every combo of the mode listed by name, each opening an
in-game-style strip (input above skill icon, skill after skill, "or" stacks for choice steps,
OPTIONAL captions) meant to be kept up next to the game while practicing. The no-input-capture
stance and the section layout are unchanged; ideal-combo designations still mark the default
selection.
